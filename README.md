# Content Hub Egypt — MVP
1. `cp .env.example .env.local` وضع المفتاح العام (sb_publishable) فقط.
2. `npm install && npm run dev`
3. أنشئ حساب أدمن: غيّر `role` لمستخدم موجود من SQL Editor (من الخادم فقط، لا من الواجهة).
## ملاحظات
- كل العمليات المالية والمراجعة عبر دوال RPC الموجودة في قاعدة البيانات.
- المشاهدات الموثّقة تُدخَل في `view_snapshots` بواسطة الأدمن؛ لا توجد واجهة لإدخالها في هذه النسخة.
- لم يُنفَّذ بعد: التحليلات، المجتمعات، الإشعارات، الملف الشخصي، رفع الصور، الإنجليزية، إيقاف/إلغاء الحملة، FAQ/Referrals/Disputes للأدمن.
